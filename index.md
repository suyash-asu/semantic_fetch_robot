# Semantic Fetch Robot

## Project Overview

This project implements a **ROS2-based semantic fetch robot** capable of receiving high-level object requests and navigating to retrieve them.

This website documents the progress of the project across milestones.

---

## Milestone 1

Milestone 1 focuses on establishing the basic ROS2 package structure.

### Completed Tasks

- Created ROS2 Python package
- Configured dependencies
- Implemented minimal ROS2 node
- Verified successful workspace build
